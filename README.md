# Canais 🔔

Uma extensão leve para o navegador que monitora seus criadores favoritos no YouTube, Kick e Twitch, avisando na hora quando entram ao vivo ou lançam vídeos novos.

---

## Funcionalidades

# Suporte a YouTube, Kick e Twitch

Acompanhe o status das transmissões em tempo real nas três principais plataformas.

# Notificação e Abertura de Lives

Receba alertas assim que o canal entrar ao vivo ou configure para abrir a transmissão automaticamente no navegador.

# Monitoramento de Novos Vídeos (YouTube)

Opções dedicadas para notificar a publicação de novos vídeos e abrir o link do vídeo novo automaticamente.

# Painel de Controle por Canal

Cada canal adicionado possui um menu de configurações individuais onde você pode:

* Pausar o monitoramento temporariamente
* Ativar ou desativar a abertura automática de lives
* Ativar ou desativar notificações de novos vídeos
* Ativar ou desativar a abertura automática de novos vídeos

# Ajuste do Intervalo de Verificação

Defina nas configurações de forma simples de quanto em quanto tempo a extensão deve checar as plataformas.

# Ações Rápidas na Lista

* Botão de play para ir direto para a live do canal
* Botão de sino para alternar notificações
* Botão de busca rápida no canal
* Menu de opções rápidas
* Botão para remover canal da lista
* Opção para verificar todos os canais manualmente com um clique

# Indicador no Ícone

Exibe um contador de lives ativas diretamente no ícone da extensão.

## Passo a Passo para Instalar no Navegador

Como a extensão ainda não está na loja oficial do Chrome, o processo de instalação é simples e leva menos de dois minutos:

1. Fazer o Download do Projeto
No topo desta página do GitHub, clique no botão verde chamado Code e selecione a opção Download ZIP.
2. Extrair a Pasta do Arquivo
Vá até a sua pasta de Downloads no computador. Clique com o botão direito no arquivo baixado e selecione Extrair tudo... para descompactar os arquivos numa pasta normal.


3. Acessar as Extensões do Navegador
Abra o seu navegador (Google Chrome, Edge, Brave ou Opera) e digite o seguinte endereço na barra de navegação:
chrome://extensions/
4. Ativar o Modo do Desenvolvedor
No canto superior direito da página de extensões, ative a chave com o nome Modo do programador ou Modo do desenvolvedor.
5. Carregar a Extensão
No canto superior esquerdo, clique no botão Carregar sem compactação (ou Load unpacked).
6. Selecionar a Pasta
Navegue até a pasta que você extraiu no Passo 2, clique nela apenas uma vez para selecionar e confirme clicando em Selecionar pasta.



Pronto! A extensão Canais estará instalada e pronta para ser usada.

---

## Como Usar

1. Clique no ícone da extensão Canais na barra do seu navegador.
2. Escolha a aba da plataforma desejada (YouTube, Kick ou Twitch).


3. Digite o @canal ou a URL no campo de busca.


4. Escolha as preferências padrão de Notificar ou Abrir auto e clique em + Adicionar.


5. Para ajustar um canal específico, clique no ícone de menu ao lado dele para personalizar o monitoramento.
